# Contributing to MPOnline Project

Thank you for contributing.

## Development Workflow

1. Create or select an issue.
2. Branch from `develop`.
3. Implement and test the change.
4. Run frontend lint/build and backend syntax checks.
5. Use clear Conventional Commit-style messages such as `feat:`, `fix:`, `docs:`, or `refactor:`.
6. Push the branch and open a pull request into `develop`.
7. Explain what changed, why, and how it was tested.

## Security

Do not commit secrets, .env files, API keys, passwords, tokens, or personal data.
