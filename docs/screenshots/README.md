# Screenshot Checklist

Screenshots are intentionally kept as a submission asset rather than generated placeholders. Add real screenshots from the running application here before the final hackathon submission.

## Required screenshots

| Priority | Filename | Screen | What the judge should notice |
|---|---|---|---|
| P0 | dashboard.png | Student dashboard | Overall product and navigation |
| P0 | skill-gap.png | AI/profile analysis | Personalized strengths, gaps and actions |
| P0 | resume.png | Resume Enhancer | PDF parsing + AI review |
| P0 | interview.png | Mock Interview | Question -> answer -> feedback |
| P0 | opportunities.png | Opportunities | Source/freshness transparency |
| P1 | admin.png | Admin/analytics | Placement/skill-trend view |

## Capture rules

- Use the same demo student persona across screenshots.
- Crop out browser tabs, bookmarks and personal information.
- Keep the application at a readable desktop resolution.
- Prefer one strong screenshot per feature over many similar images.
- Use real application output; do not use mock data that is not present in the product.
