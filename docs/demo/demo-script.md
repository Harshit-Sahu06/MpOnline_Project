# 3-Minute Judge Demo Script

## 0:00-0:20 — Problem

> Students often know they want a job, but do not know where they currently stand, which skills they are missing, or what to do next.

Show the landing/login screen.

## 0:20-0:40 — Solution

> Campus to Corporate connects the employability journey in one flow: assess, identify gaps, act, prepare and discover opportunities.

Show the main dashboard and navigation.

## 0:40-1:10 — AI assessment

- Open the student profile.
- Run profile analysis.
- Show strengths, gaps and recommended actions.
- Explain that the backend keeps the Gemini key private.

Key line:

> The AI is used for personalization, not as a generic chatbot.

## 1:10-1:35 — Resume improvement

- Open Resume Enhancer.
- Upload a PDF resume.
- Show extracted text.
- Run resume review.
- Highlight concrete improvement suggestions.

Key line:

> A student's existing resume becomes structured input for the rest of the employability workflow.

## 1:35-1:55 — Interview preparation

- Open mock interview.
- Start a question.
- Submit an answer.
- Show feedback.

Key line:

> Preparation is connected to the same profile instead of being an isolated practice tool.

## 1:55-2:15 — Opportunities

- Open jobs/opportunities.
- Show source and freshness metadata.
- Point out the official National Career Service source.

Key line:

> We prefer transparent source metadata over fabricated live opportunities.

## 2:15-2:35 — Technical architecture

Show the architecture diagram.

Mention:

- React + Vite
- Express REST API
- JWT + HttpOnly cookie
- JSON-backed persistence for the prototype
- Gemini AI
- PDF parsing
- verified NCS opportunity source
- GitHub Actions CI

## 2:35-3:00 — Closing

> Campus to Corporate turns employability from a vague question into an actionable roadmap: understand your current state, close the gaps, prepare better, and discover relevant opportunities.

## Demo discipline

- Keep the demo under 3 minutes.
- Use one student persona from start to finish.
- Do not open unrelated screens.
- If Gemini is unavailable, explain the deterministic fallback rather than pretending it is live AI.
- Keep a prepared PDF resume ready.
